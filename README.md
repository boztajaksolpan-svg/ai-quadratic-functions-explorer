# AI Quadratic Functions Explorer

## Project Overview

AI Quadratic Functions Explorer is an interactive mathematics learning application developed for the Educational Technology & AI course.

The application uses Google Gemini AI and Python to support differentiated learning through quadratic functions, interactive graphs, and mathematical explanations.

## Difficulty Levels

- **Basic:** Find the roots of simple quadratic functions.
- **Standard:** Find the roots and vertex of a quadratic function.
- **Advanced:** Solve real-world quadratic function problems involving the motion of a ball, maximum height, and time.

## Main Features

- AI-assisted mathematics problem generation
- Three difficulty levels
- Interactive parabola graphs
- Automatic answer checking
- AI-powered mathematical hints
- Step-by-step solutions
- Different practice problems

## Technologies Used

- Python
- Streamlit
- Google Gemini API
- Plotly
- GitHub
- Streamlit Community Cloud

## How It Works

1. Select Basic, Standard, or Advanced.
2. Click "Generate AI Problem".
3. Read the mathematical problem.
4. Enter your answers.
5. Click "Check Answer" to receive feedback.
6. Use "Get AI Hint" for guidance.
7. Explore the interactive graph and mathematical solution.

## AI Integration

Google Gemini AI proposes mathematical problem parameters and provides hints based on the selected difficulty level.

Python constructs and validates the mathematical problems, checks student answers, and supports step-by-step explanations.

## Testing

The application was tested at all three difficulty levels. Problem generation, answer checking, AI hints, and mathematical graphs were tested.

## Academic Purpose

This project demonstrates how artificial intelligence can support differentiated mathematics education by adapting problem difficulty and learning guidance to students' abilities.
